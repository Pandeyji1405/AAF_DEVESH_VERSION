Case Manager = Which specialist should handle this?
Device Ops Specialist = What is happening, and what approved action should we take?
Policy = Are we allowed to take that action?
AutomationEdge = Execute the approved action.

Device Specialist decides WHAT should be done.
Policy decides WHETHER it is allowed.
AutomationEdge actually DOES it.

Risk level → defined in the tool catalog
Permission/approval → evaluated by the Policy Decision Point
AI agent → proposes/selects the action
AutomationEdge → executes only after authorization

Device Ops Specialist (AI)
→ Understands the device problem
→ Gathers information
→ Creates the remediation plan
→ Selects the approved tool/action.

Tool Metadata
→ Defines the action's risk tier and required approval type.

Policy Decision Point (normal deterministic component, NOT AI)
→ Checks whether that action is actually allowed for this requester, target, scope, risk, approval, maintenance window, etc.

AutomationEdge
→ Executes the action only after it is authorized.
